# Public Protocol Record Template

**Source-linked discovery record. It does not replace the original protocol.**

[Nominate a public protocol](https://github.com/PhysioVerse-OSE/mps-protocol-commons/issues/new?template=resource-nomination.yml) · [Review protocol tasks](https://github.com/PhysioVerse-OSE/mps-protocol-commons/issues)

Nominate an existing protocol, SOP reference, or methods resource. Preserve the original author, version, and source. Public availability does not automatically grant permission to republish the full text.

## Nomination and Review

Explain why the resource is useful and which information is missing. A protocol listing should not be interpreted as endorsement, proof of reproducibility, or formal validation. Record review comments and sources before an accepted record is incorporated.

Use the original source for operational details. Do not copy restricted SOPs into GitHub. Send Mostafa the contribution link after submitting.
